# Livestream Promotion Pilot

## Archive Note

该方向曾是候选 Pilot。团队后来把第一条 AI Native 主线确定为自媒体运营，因此本记录不再进入默认执行上下文。直播宣传仍可在未来重新提案，但必须按统一的部门接入和 Pilot 生命周期重新评估。

## Candidate Outcome

在活动信息确认后，由 Agent 生成多渠道宣传草稿和发布清单，人在事实、品牌和最终发布节点确认。

## Why This Pilot

- 输入相对明确；
- 重复频率较高；
- 输出可在发布前完整审核；
- 失败不会直接改变生产系统；
- 能同时验证 Context、Skill、Workflow、Tool、Human Gate 和 Eval。

## Required Evidence Before Skill Creation

- 至少 3 次历史直播活动的完整输入与最终物料；
- 哪些版本被采用、被修改或被拒绝；
- 各渠道字数、格式和发布时间要求；
- 时间、嘉宾、链接、价格、福利等硬事实的权威来源；
- 当前人工耗时、返工原因和发布审批人。

## Boundary

目前只定义 Pilot 方向，尚未形成经验证的 Active Skill。不得依据本文件自动发布内容。
