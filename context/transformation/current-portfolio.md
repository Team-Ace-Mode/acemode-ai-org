## Current Responsibilities

- AI Transformation Lead：完成组织框架、Brain、Skill 标准和生命周期。
- PM：与需求方梳理真实流程并形成 PRD。
- 自媒体运营 TPM / 需求方：提供现状、输入、交付物、痛点、例外和历史案例。
- Developer / AI Ops：在范围确认后实现工具和运行环境。
- Founder 或获授权的 Lead：验收 Pilot 是否满足组织目标。

## Promotion Criteria for the First Pilot

进入实现前必须明确：Domain Owner、Approver、当前人工流程、至少三个真实案例、输入和输出、人工节点、失败停止条件以及基线指标。具体功能和工具选择属于后续 PRD 与 Workflow，不写入本文件。

## Known Risks

- 需求、技术和验收集中在少数成员，存在关键人依赖。
- 业务资产分散在微信和腾讯文档，权威来源尚未制度化。
- 团队尚未定义统一的成功指标和回退条件。
