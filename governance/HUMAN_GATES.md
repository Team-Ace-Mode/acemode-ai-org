# Human Gates

人工节点的目的不是逐字替 Agent 工作，而是让不可委托的责任有明确承担者。

## 风险级别

| 级别 | 示例 | 默认处理 |
| --- | --- | --- |
| H0 自动 | 读取 Active Context、内部摘要、结构化整理 | 可自动执行并记录 |
| H1 审阅 | 内容初稿、选题建议、内部分析 | Agent 可完成，人抽检或反馈 |
| H2 批准 | 对外发布、联系嘉宾/用户、付费生成、品牌主张、测评结论 | 执行前必须明确批准 |
| H3 人工专属 | 生产部署、删除数据、权限/密钥变更、转账、法律承诺、未经验证的真实体验判断 | Agent 只能准备材料，不得执行最终动作 |

## 必须设置 Gate 的动作

- 对外发布或发送；
- 产生费用或绑定付费承诺；
- 删除、覆盖或不可逆改变数据；
- 生产环境、数据库迁移、访问权限和密钥变更；
- 嘉宾身份、时间、价格、福利、商业合作等硬事实；
- 产品测评的真实体验和最终推荐结论；
- 涉及隐私、法律、医疗、财务或公共风险的内容。

## 审批包

Agent 必须给审批人提供：

1. 拟执行动作和目标对象；
2. 完整预览或 Diff；
3. 关键事实及来源；
4. 已运行的质量检查；
5. 成本、风险和失败影响；
6. 可撤销或恢复方式；
7. 批准的有效范围和过期时间。

“看起来可以”“之后再看”和沉默都不构成批准。批准一次不等于以后同类动作永久自动化。
