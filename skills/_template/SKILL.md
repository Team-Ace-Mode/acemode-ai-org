# Skill Name

## Overview

## When to Use

- 明确不适用场景。

## Required Inputs

- 输入名称、格式、权威来源。
- 缺失时必须停止还是可以降级。

## Context to Read

## Workflow

2. 按领域方法产出草稿。
3. 执行质量检查。
4. 在规定 Gate 暂停或交付。

## Quality Checks

- 绝不能发生的错误。

## Failure Handling

- 信息缺失、工具失败、事实冲突和审批拒绝时如何停止或恢复。
